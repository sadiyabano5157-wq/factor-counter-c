# factor-counter-c
C program to print all factors of a number and count the total number of factors using loops and conditions.


# Factor Counter Program in C

## 📌 Description
This C program prints all factors of a given number and counts the total factors.

## 🚀 Features
- User input
- Prints all factors
- Counts total factors

## 🧠 Concepts Used
- for loop
- if condition
- modulus operator
- counting logic

## 💻 Example

Input:
12

Output:
1
2
3
4
6
12

Total count of factor 6
